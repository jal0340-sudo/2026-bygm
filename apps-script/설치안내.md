# 글틔움 저장 기능 설치 안내 (선생님용)

학생이 [저장]을 누르면 **선생님 구글 드라이브 › `글틔움` 폴더**에 `학번 이름` 제목의 구글 문서로 저장됩니다.
같은 학번·이름으로 다시 저장하면 같은 문서에 **덮어씁니다**. 다음에 같은 학번·이름으로 로그인하면 저장된 글을 불러옵니다.

처음 한 번만 아래 순서대로 설정하면 됩니다. (약 5분)

## 1. Apps Script 프로젝트 만들기
1. 크롬에서 **jal0340@gmail.com** 계정으로 로그인된 상태인지 확인합니다.
2. <https://script.google.com> 에 들어가 **[새 프로젝트]** 를 누릅니다.
3. 프로젝트 이름을 `글틔움 저장`으로 바꿉니다.
4. 편집기의 `Code.gs` 내용을 모두 지우고, 이 폴더의 [`Code.gs`](Code.gs) 내용을 그대로 붙여 넣은 뒤 저장(Ctrl+S)합니다.

## 2. 권한 승인 (폴더 만들기)
1. 위쪽 함수 선택 칸에서 `setup` 을 고르고 **[실행]** 을 누릅니다.
2. "승인 필요" 창이 뜨면 **권한 검토 → jal0340@gmail.com 선택 → 고급 → '글틔움 저장(안전하지 않음)'으로 이동 → 허용** 을 누릅니다.
   (선생님이 직접 만든 스크립트라서 나오는 안내입니다.)
3. 실행 로그에 `폴더 준비 완료`가 나오고, 드라이브에 `글틔움` 폴더가 생깁니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **[배포] → [새 배포]** 를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱** 을 고릅니다.
3. 다음처럼 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나(jal0340@gmail.com)**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **[배포]** 를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 글틔움에 주소 넣기
`index.html` 에서 다음 줄을 찾아 따옴표 안에 복사한 주소를 넣습니다.

```js
const SAVE_URL = '';
```

Claude에게 "저장 주소는 https://script.google.com/macros/s/…/exec 야" 라고 알려 주면 대신 넣고 배포해 드립니다.

## 알아 두기
- 학생은 구글 계정이 없어도 학번·이름만으로 저장할 수 있습니다. 그 대신 비밀번호가 없어서, 다른 학생의 학번·이름을 쓰면 그 글을 불러오거나 덮어쓸 수 있습니다. 수업 중에 안내해 주세요.
- 로그인 정보는 브라우저 탭을 닫으면 지워집니다. (공용 컴퓨터에서도 다음 학생에게 남지 않음)
- `Code.gs` 를 고친 뒤에는 **[배포] → [배포 관리] → 연필 → 버전: 새 버전 → [배포]** 로 다시 배포해야 반영됩니다. 이때 URL은 그대로입니다.
