# 글틔움 서버 구성 안내

글틔움에는 서버가 두 가지 있습니다.

| 구분 | 코드 | 누가 배포 | 보관하는 것 |
|---|---|---|---|
| **수업 목록 서버** | `apps-script/Code.gs` | 글틔움 운영자(jal0340@gmail.com) 한 번 | 수업명 · 수업 코드 · 저장 서버 주소 · 개설일 · 마지막 저장일 |
| **저장 서버** | `save-server/Code.gs` | 수업을 개설하는 선생님마다 각자 | 학생 글(구글 문서) · 학생 비밀번호(해시) |

학생 글과 비밀번호는 수업 목록 서버를 거치지 않고, 수업을 개설한 선생님의 저장 서버로 바로 갑니다.
저장 문서 제목은 `수업명(학번 이름)`이고, 그 선생님 드라이브의 `글틔움` 폴더에 저장됩니다. 다시 저장하면 덮어씁니다.

## 선생님이 수업을 개설하는 방법
글틔움 오른쪽 위 **[선생님 설정]** 화면에 순서대로 안내되어 있습니다.
1. [저장 서버 코드 복사] → <https://script.new> 에 붙여 넣고 저장
2. [배포] → [새 배포] → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → 액세스 승인
3. 웹 앱 URL과 수업명을 넣고 [수업 개설하고 코드 받기] → 6자리 수업 코드가 자동으로 만들어짐

- 수업 코드는 겹치지 않게 자동으로 만들어집니다. (헷갈리는 0·O·1·I·L 제외)
- 저장 서버 하나로 수업을 여러 개 개설할 수 있습니다. 같은 저장 서버 안에서 수업명은 겹칠 수 없습니다.
- 수업 코드는 선생님 드라이브 `글틔움` 폴더의 `글틔움 수업 코드 목록` 문서에도 기록됩니다.
- 개설된 수업은 누구도 지울 수 없고, [개설된 수업 보기]에서 확인만 할 수 있습니다. (수업 코드는 앞 두 자리만 표시)
- **1년 동안 그 수업 코드로 새로 저장된 글이 없으면** 수업과 수업 코드가 자동으로 삭제되고 저장 서버 연결이 해제됩니다. 학생 글이 저장될 때마다 1년이 다시 시작됩니다. 이미 저장된 글 문서는 선생님 드라이브에 그대로 남습니다.

## 학생이 비밀번호를 잊었을 때 (선생님 저장 서버에서)
1. 선생님의 Apps Script 편집기에서 `resetPassword` 함수 안의 `CODE`(수업 코드)와 `WHO`(`학번 이름`)를 바꿉니다.
2. 함수 선택 칸에서 `resetPassword` 를 고르고 **[실행]** 합니다. 학생은 다음 로그인 때 새 비밀번호를 정합니다. 글은 그대로 남습니다.
3. `listClasses` 를 실행하면 연결된 수업과 학생 수를 볼 수 있습니다.
