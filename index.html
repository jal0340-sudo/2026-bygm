선생님 설정 수업 개설

수업을 개설하면 학생들이 쓴 글이 개설한 선생님 본인의 구글 드라이브 › ‘글틔움’ 폴더에 ‘수업명(학번 이름)’ 문서로 저장돼요. 학생은 첫 화면에서 수업 코드를 쓰고 로그인해요.

1학생 글을 저장할 구글 계정 연결하기 처음 한 번만

  1. 를 누르세요.
  2. 학생 글을 저장할 구글 계정으로 로그인한 상태에서 Apps Script 새 프로젝트 열기 ↗를 누르세요.
  3. 편집기에 있는 내용을 모두 지우고, 복사한 코드를 붙여 넣은 뒤 저장(Ctrl+S)하세요. 프로젝트 이름은 ‘글틔움 저장 서버’처럼 바꿔 두면 좋아요.
  4. 오른쪽 위 [배포] → [새 배포]를 누르고, 톱니바퀴(유형 선택)에서 웹 앱을 고르세요.
    다음 사용자 인증 정보로 실행: 나 · 액세스 권한이 있는 사용자: 모든 사용자로 정하고 [배포]를 누르세요.
  5. [액세스 승인] → 계정 선택 → 고급 → ‘(프로젝트 이름)(으)로 이동’ → 허용을 누르세요. 선생님이 직접 만든 스크립트라서 나오는 안내예요.
  6. 나온 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사해 아래 ‘저장 서버 주소’ 칸에 붙여 넣으세요.

이미 만든 저장 서버가 있다면 같은 주소로 수업을 여러 개 개설할 수 있어요. 학생 비밀번호는 원문이 아니라 암호화된 값으로만 선생님 저장 서버에 보관돼요.

2수업 개설하기

수업 코드는 다른 수업과 겹치지 않게 자동으로 만들어져요. 관리 비밀번호는 나중에 수업명을 바꿀 때 필요해요. 개설한 선생님만 알고 있도록 잘 기억해 두세요.

학생들에게 이 수업 코드를 알려 주세요. 자동 삭제 예정일: (그 전에 학생 글이 저장되면 다시 1년 뒤로 늘어나요)

코드는 선생님 드라이브 ‘글틔움’ 폴더의 ‘글틔움 수업 코드 목록’ 문서에도 적혀 있어요. [개설된 수업 보기]에서는 학생 보호를 위해 코드 앞 두 자리만 보여요.

⚠ 꼭 알아 두세요
  • 1년 동안 이 수업 코드로 새로 저장되는 글(파일)이 없으면, 수업과 수업 코드가 자동으로 삭제되고 연결된 선생님 계정도 연결이 해제돼요. 학생이 글을 저장할 때마다 1년이 새로 시작돼요.
  • 자동 삭제되어도 이미 저장된 학생 글 문서는 선생님 드라이브에 그대로 남아요. 같은 수업을 다시 쓰려면 새로 개설해 새 코드를 받으면 돼요.
  • 한 번 개설된 수업은 다른 선생님이 지울 수 없어요. 대신 [개설된 수업 보기]에서 어떤 수업이 개설되어 있는지 확인할 수 있어요.
  • 수업명은 개설한 선생님만 아래 3번에서 관리 비밀번호로 바꿀 수 있어요.
